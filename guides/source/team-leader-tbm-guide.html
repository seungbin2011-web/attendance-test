1단계

로그인

「현장 업무 통합 로그인」 화면에서 로그인합니다.

  1. 1이름을 입력합니다.
  2. 2휴대폰 번호 뒤 4자리를 입력합니다.
  3. 3로그인 버튼을 누릅니다.
예) 휴대폰 번호가 010-1234-5678이면
5678을 입력합니다.

오늘 작업계획 작성

작업 위치와 작업내용을 입력하고 투입 인원을 선택합니다. 작업이 여러 개면 「+ 작업 추가」를 눌러 추가합니다.

  1. 1작업 위치를 입력합니다.
  2. 2작업 내용을 입력합니다.
  3. 3이 작업에 들어갈 투입 인원을 체크합니다.
  4. 4작업이 더 있으면 + 작업 추가

3단계

위험요인 · 안전조치 입력 후 저장

화면을 아래로 내려 위험요인과 안전조치를 입력합니다. 입력이 끝나면 「작업계획 저장」을 누릅니다.

  1. 1해당하는 위험요인을 모두 체크합니다.
  2. 2안전조치 / 전달사항을 적습니다.
  3. 3소장님께 알릴 내용은 특이사항에 적습니다.
  4. 4작업계획 저장을 누릅니다.
  5. ✓「서버 저장됨」이 보이면 끝입니다.
소장님 확인이 필요하면 「소장 확인 필요」에 체크합니다.

4
4단계 · 작업 시작 전

출근 TBM

작업 시작 전 작업계획을 확인합니다. 필요한 전달사항과 현장 사진을 등록한 뒤 「출근 TBM 보고」를 누릅니다.

  1. 1홈 화면에서 파란색 출근 TBM
  2. 2추가 전달사항을 적습니다.
  3. 3「파일 선택」으로 현장 사진 등록 (최대 3장)
  4. 4출근 TBM 보고를 누릅니다.

✓ 「출근 TBM 보고 완료」로 바뀌면 끝입니다.

5단계 · 오후

오후 TBM

작업 상태를 정상 / 변경 / 지연 / 위험 중 선택합니다. 변경사항이 있는 작업만 내용을 기록하고 사진을 등록합니다.

  1. 1홈 화면에서 주황색 오후 TBM
  2. 2작업마다 정상 · 변경 · 지연 · 위험 중 하나를 누릅니다.
  3. 3「파일 선택」으로 현장 사진을 등록합니다.
  4. ✓「모든 작업 확인됨」과 「서버 저장됨」을 확인합니다.
계획대로 진행 중이면 「정상」만 누르면 됩니다. 전체에 알릴 말은 오후 전달사항(선택)에 적습니다.

6단계 · 작업 종료

퇴근 TBM 및 마감

각 작업을 완료 / 일부완료 / 미완료 / 제외로 선택합니다. 최종 사진과 전달사항을 입력한 뒤 「퇴근 TBM 마감」을 누릅니다.

  1. 1홈 화면에서 남색 퇴근 TBM
  2. 2작업마다 결과를 하나 누릅니다.
  3. 3「파일 선택」으로 최종 현장 사진 등록
  4. 4퇴근 공통 전달사항을 적습니다. (선택)
  5. 5퇴근 TBM 마감을 누릅니다.

✓ 「서버 저장됨 · 마감」이 보이면 끝입니다.

일부완료 · 미완료 작업은 사유와 내일 이월 여부를 적습니다.

7단계 · 같은 날 추가 작업

완료 후 새 작업 열기

퇴근 TBM까지 마감한 작업은 수정하지 않고 기록으로 보존됩니다. 같은 날 추가 작업이 생기면 「+ 새 작업 열기」를 눌러 새 작업계획을 시작합니다.

  1. 1+ 새 작업 열기를 누릅니다.
  2. 2마감한 작업은 내용 보기로 확인만 할 수 있습니다.
  3. ✓새 작업이 열리면 2단계 작업계획부터 다시 진행합니다.
