팀별 TBM 보고를 휴대폰으로 확인하는 방법입니다.

  1. 1로그인이름 + 휴대폰 뒤 4자리
  2. 2현장 TBM 현황 보기숫자로 한눈에
  3. 3팀별 보고 상태 확인전체 · 확인 필요 · 미보고
  4. 4팀 보고 상세 보기「상세 보기」
  5. 5현장 사진 · 변경 이력출근 · 오후 · 퇴근 사진

로그인

팀장과 같은 「현장 업무 통합 로그인」 화면을 씁니다. 로그인하면 「현장 TBM 현황」 화면이 열립니다.

  1. 1이름을 입력합니다.
  2. 2휴대폰 번호 뒤 4자리를 입력합니다.
  3. 3로그인 버튼을 누릅니다.
예) 휴대폰 번호가 010-1234-5678이면
5678을 입력합니다.

팀별 보고 상태 확인

숫자 칸 아래에 팀별 보고 카드가 나옵니다. 버튼을 눌러 보고 싶은 팀만 골라 볼 수 있습니다.

  1. 1전체 확인 필요 미보고 중 하나를 누릅니다.
  2. ✓출근 · 오후 · 퇴근 옆 시간은 각 TBM을 보고한 시간입니다.
  3. ✓「미보고」는 오늘 작업계획이 아직 없는 팀입니다.
「확인 필요」는 팀장이 「소장 확인 필요」를 표시했거나 위험 작업이 있는 팀입니다.

카드에서 특이사항, 작업 결과(완료 등), 사진 장수도 바로 볼 수 있습니다.

팀 보고 상세 보기

팀 카드의 「상세 보기」를 누르면 그 팀의 보고 내용을 모두 볼 수 있습니다.

  1. 1상세 보기를 누릅니다.
  2. ✓보고자 · 위험요인 · 안전조치 · 특이사항과 출근 · 오후 · 퇴근 TBM 시간과 내용을 확인합니다.
  3. ✓작업마다 작업 내용 · 투입 인원 · 오후 상태 · 퇴근 결과를 확인합니다.
  4. 2목록을 누르면 팀 목록으로 돌아갑니다.

현장 사진 · 변경 이력

상세 화면을 아래로 내리면 팀장이 보고한 실제 현장 사진과 변경 이력이 나옵니다. 소장 화면에서는 조회만 합니다.

  1. ✓출근 TBM · 오후 TBM · 퇴근 TBM 사진이 차례로 나옵니다. 사진마다 시간이 표시됩니다.
  2. ✓변경 이력에서 누가 언제 무엇을 했는지 확인합니다. 최근 기록이 맨 위에 나옵니다.

예: 출근 TBM 보고 · 작업 정상 · 사진 추가 · 퇴근 결과 입력 · 퇴근 TBM 마감
