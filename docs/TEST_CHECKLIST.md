# 현장 실테스트 체크리스트 (휴대폰)

- 링크는 하나만 씁니다: `https://seungbin2011-web.github.io/attendance-test/`
- 입력은 **이름 + 휴대폰 번호 뒤 4자리**뿐입니다.
- 대표 브라우저는 **iPhone Chrome**입니다. 따로 적지 않은 항목은 iPhone Chrome으로 확인합니다. iPhone Safari는 같은 대응이 들어 있어 보조로 확인합니다.
- 역할마다 실제 인원 1명씩, 본인 휴대폰으로 확인합니다. 번호나 결과 화면 캡처를 채팅·메신저에 올리지 않습니다.
- 문제가 나오면 `docs/BACKLOG_FIELD_TEST.md`에 적습니다 (언제·누가·어느 화면·무엇을 눌렀는지·화면 문구).

## 공통 (모든 역할)

- [ ] 링크를 열면 "현장 업무 통합 로그인" 화면이 나오고, TEST·시험 표시가 없다
- [ ] 틀린 번호를 넣으면 "이름 또는 휴대폰 번호 뒤 4자리가 일치하지 않습니다"가 나오고 로그인되지 않는다
- [ ] 이름에 공백을 넣거나 빼도 같은 사람으로 로그인된다 (공백 정리)
- [ ] 로그인 후 화면 맨 위 이름·팀·역할이 본인 정보와 맞다
- [ ] 새로고침해도 로그인이 유지되고 같은 화면에 남는다
- [ ] 로그아웃하면 로그인 화면으로 돌아가고, 뒤로가기로 업무 화면이 다시 열리지 않는다
- [ ] 화면 어디에도 주소에 `_test`가 들어간 링크가 없다

## MEMBER (일반 팀원)

- [ ] 로그인 → 팀원 화면(`member.html`)으로 이동한다
- [ ] "우리 팀장·팀원"에 본인 팀 인원이 나오고, 다른 팀 인원이나 퇴사자는 나오지 않는다
- [ ] "출결 등록"을 누르면 기존 출퇴근 화면(`index_season1.html`)이 열린다 (기존 임시 암호 방식)
- [ ] 접근 금지: 주소창에서 `tbm_report.html` → "팀장만 사용할 수 있는 화면" 안내가 나온다
- [ ] 접근 금지: `tbm_manager.html` → 현장관리·관리자만 사용할 수 있다는 안내가 나온다
- [ ] 접근 금지: `organization.html` → "현장관리·관리자만 볼 수 있는 화면" 안내가 나온다

## TEAM_LEADER (팀장)

- [ ] 로그인 → 팀장 TBM(`tbm_report.html`)으로 이동하고, 맨 위에 본인 팀·이름·팀장이 보인다
- [ ] 작업 인원 후보에 우리 팀 현재 인원만 나온다 (다른 팀·퇴사자 없음)
- [ ] 같은 팀 팀장이 여러 명이면 같은 보고를 함께 보고 고칠 수 있다
- [ ] 접근 금지: `tbm_manager.html`, `organization.html`은 막힌다

## SITE_MANAGER (소장·현장관리)

- [ ] 로그인 → 현장 TBM 현황(`tbm_manager.html`)으로 이동한다
- [ ] 모든 팀 카드가 보이고, 팀을 누르면 보고 상세(작업·인원·사진)가 열린다
- [ ] 조직도(`organization.html`)가 열린다. 전화번호·출입증번호는 나오지 않는다
- [ ] 접근 금지: `tbm_report.html`은 팀장 화면이라 막힌다
- [ ] 인원 편집 기능은 없다 (관리자만 가능)

## ADMIN (관리자)

- [ ] 로그인 → 같은 주소에서 관리자 명부가 열린다
- [ ] 상단 "로그인 번호 등록"이 `53 / 53`이다 (인원을 추가하면 숫자가 바뀐다)
- [ ] 조직도와 현장 TBM 현황도 열린다

## 업무 흐름 (팀장 1명 + 소장 1명이 같이 확인)

- [ ] 작업계획: 팀장이 오늘 작업(장소·내용·인원·위험요인)을 저장한다 → "저장됨"이 나온다
- [ ] 출근 TBM: 팀장이 보고한다 → 소장 현황에 해당 팀이 "보고됨"으로 보인다
- [ ] 사진: 출근 TBM 사진을 올린다. 한 번에 3장까지이고, 4장째는 안내가 나온다 → 소장 상세에서 사진이 열린다
- [ ] 오후 TBM: "전체 이상 없음" 또는 작업별 변경·지연·위험을 저장한다 → 소장 현황에 반영된다
- [ ] 퇴근 TBM: 작업별 결과(완료·일부완료·미완료·제외)를 입력하고 마감한다
- [ ] 미완료: 미완료·일부완료는 사유 없이 저장되지 않는다
- [ ] 다음날 이월: 미완료 작업을 "내일 이월"로 적고, 다음 날 팀장 작업계획에 "이전 작업 이월"로 나온다 (다음 날 확인)
- [ ] 팀장 보고: 하루 전체(출근·오후·퇴근) 기록이 팀장 화면에 남아 있다
- [ ] 소장 현황: 자동 새로고침과 변경 이력이 보이고, 다른 팀 보고도 볼 수 있다 (읽기 전용)
- [ ] 관리자 인원관리
  - 시험용으로 실제 인원이 아닌 이름을 쓴다.
  - [ ] 인원 추가(이름·뒤 4자리·팀·권한) → 그 이름과 번호로 바로 로그인된다
  - [ ] 팀 이동·권한 변경 → 다음 로그인부터 반영된다
  - [ ] 비활성 → 로그인이 막힌다
  - 시험이 끝나면 그 인원을 비활성으로 돌린다.

## 실패로 볼 것

- 다른 사람 이름으로 로그인되거나, 다른 팀 보고가 수정된다
- 비활성(퇴사) 인원이 로그인된다
- 저장 실패인데 "저장됨"이 표시된다
- 운영 화면에 TEST·시험 표시나 `_test` 주소가 나온다
