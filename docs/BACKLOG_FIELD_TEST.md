# 현장 실사용 테스트 백로그

현장 테스트에서 나온 문제와 개선 후보를 모은다. **여기 적힌 것은 구현 결정이 아니다.** 사용자와 검토한 뒤 하나씩 진행한다.
항목 형식: 제목 / 내용 / 개선 후보 / 상태(검토 대기 · 진행 중 · 완료 · 보류) / 발견일·출처

---

## 1. [소장 화면] 확인 행동이 없음

- 내용: 지금 소장 화면은 조회 기능 위주다. 보고 내용을 확인한 뒤 소장이 할 수 있는 행동이 없다.
- 개선 후보
  - 팀별 보고에 "소장 확인" 버튼
  - 확인자 기록
  - 확인 시간 기록
  - 팀장 화면에서 소장 확인 여부 표시
- 참고 (코드 기준)
  - `field_pilot_v1.daily_reports.status`에 이미 `CONFIRMED` 값이 정의돼 있고, `CONFIRMED`가 된 보고는 팀장이 고칠 수 없게 돼 있다.
  - 팀장 화면에는 "소장 확인 필요" 체크(`needs_manager_check`)가 있다.
  - 상태를 `CONFIRMED`로 바꾸는 서버 함수와 화면 버튼은 없다.
- 상태: 검토 대기 (아직 구현하지 않는다)
- 발견: 2026-10-05, 사용자

## 2. [시험] 최초 로그인 이관 제거 후 e2e 기대값 불일치

- 내용
  - `366afcf`에서 로그인 서버의 Apps Script 최초 이관 경로를 제거했다.
  - 그런데 e2e S6(최초 이관) 3단계와, S6에서 등록된 인원을 쓰는 S8 운영 화면 3단계는 아직 이관을 전제로 해서 실패한다.
  - 앱 동작은 의도대로다 (미등록 번호 거절).
- 개선 후보
  - S6을 "미등록 번호는 거절, Apps Script 호출 0"으로 바꾼다.
  - S8은 관리자 등록 또는 시드로 번호를 넣은 인원을 쓴다.
  - 쓰지 않는 DB 함수 `pilot_member_login4_migrate`의 정리 여부는 별도로 검토한다.
- 상태: 검토 대기
- 발견: 2026-10-05, Claude (main dfcf91c 시험)

## 3. [업무계정] 팀 공용 팀장계정이 옛 팀 이름에 묶여 있음

- 내용
  - 업무계정 1팀장팀·2팀장팀은 지금 없는 팀 이름(공사1팀·공사2팀)에 묶여 있다.
  - 그래서 TBM 화면에서 "팀 정보 준비 안 됨"으로 막힌다.
  - 현장은 개인 로그인을 쓴다.
- 개선 후보: 계정을 그대로 두거나, 새 팀 이름에 연결하거나, 사용 중지한다. 업무계정은 삭제하지 않는다.
- 상태: 검토 대기
- 발견: 2026-10-05, Claude (DB 읽기 전용 조회)

## 4. [팀원 화면] "오늘 작업"이 Season 1 TBM DB를 조회함

- 내용
  - `member.html`의 "오늘 작업"은 Season 1 Apps Script TBM DB를 조회한다.
  - 그래서 Season 2 팀장 TBM에서 배정한 작업이 팀원 화면에 나오지 않는다.
- 개선 후보: Season 2 TBM(`field_pilot_v1`) 기준으로 본인 배정 작업을 보여 주는 읽기 전용 조회
- 상태: 검토 대기
- 발견: 2026-10-05, Claude (코드 기준)

## 5. [보안] Apps Script personnelOrg 공개 조회

- 내용

  - 영향: Season 1 시험 화면 일부(`admin_test.html` 등)의 인원 조회가 멈춘다.
- 상태: 검토 대기
- 발견: 2026-10-04, Claude
